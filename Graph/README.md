# Graph 案例目录

这个目录是一个面向具体案例的可视化参考目录。

其中包含：

- `data/`：案例用源 CSV
- `graph/`：已生成图像
- `scripts/`：一次性绘图脚本

## 这个目录的定位

它主要用于展示：

- 哪些图表形式适合顶会数据分析
- 如何在国家、会议、年份之间进行图形分组表达
- 论文式或汇报式图像输出大致应长什么样

不要把这个目录直接当作仓库中的通用可视化层。

仓库里的通用可视化能力由独立 skill 提供：

- `conference-visualization`

该 skill 面向现有分析产物目录工作，不依赖硬编码绝对路径，也不绑定某一个特定会议数据文件集合。
