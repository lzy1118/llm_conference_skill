# 统一采集输出目录

该目录用于集中查看采集阶段的最终有用产物。

## 子目录说明

- `output/`：统一查看入口。这里汇总了当前可用的最终输出文件，便于直接查找。
- `legacy-root-data-output/`：从仓库根目录旧 `data/output/` 复制而来的历史通用产物。
- `legacy-security-data-output/`：从 `Security-data/data/output/` 复制而来的历史通用产物。

## 当前策略

- 不删除旧目录，保留兼容。
- 新运行默认推荐直接写到 `generated-data/extraction/`。
- 已存在的历史最终输出会同步复制到这里，方便统一访问。
- 当前目录不保留 `*_us_institutions.*` 或 `*美国机构*` 这类仅美国切片文件，避免与主输出混淆。

## 注意

- `output/` 目录当前是“统一查看层”，可能同时包含历史兼容文件与新主输出。
- 当同名文件来自多个旧目录时，最后复制进来的版本会覆盖前一个版本。
- 如果后续需要更严格的版本管理，可以再细分为 `crypto/`、`security/`、`merged/` 等子目录。
- `legacy-*` 子目录表示来源路径历史，不表示美国切片或特殊统计口径。
