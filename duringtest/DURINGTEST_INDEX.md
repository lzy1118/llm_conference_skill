# duringtest 索引

## 说明

`duringtest/` 现按“保留唯一主题记录 + 合并连续阶段记录”的方式整理。

整理原则：

- 同一主题、同一天、明显连续推进的多份实验记录合并为一份总记录。
- 保留有独立研究价值或独立实验对象的单文件记录。
- 不删除模板与总归档文件。
