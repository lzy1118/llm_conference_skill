# 审计契约

## 目标

对标准化输入和分析产物生成清晰、可机器消费的质量摘要。

## 标准化数据必查项

- 必需字段缺失
- 未解析国家
- 低置信度分类行
- 作者 key 过弱或缺失
- 同一机构显示名对应多个标准化 key

## 分析产物必查项

- 预期目录与文件是否存在
- 汇总 CSV 是否为空
- markdown 报告是否缺失

## 输出结构

`quality_audit.json` 建议包含：

- `normalized_checks`
- `analysis_checks`
- `findings`
- `severity_counts`

## 严重级别建议

- `high`：缺失必需字段、输入不可读、核心输出缺失
- `medium`：未解析国家、低置信度行、重要但非核心产物缺失
- `low`：可选汇总为空、维表缺失或重复显示名等提醒项
